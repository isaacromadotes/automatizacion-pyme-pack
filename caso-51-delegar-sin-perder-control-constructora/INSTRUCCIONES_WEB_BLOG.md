## Cómo usar este pack en 2 minutos

Dentro del ZIP tienes 4 archivos: un `LEEME.md`, un `prompt.txt` y dos CSV de ejemplo (`kpis_obra.csv` y `aprobaciones.csv`).

**Importante:** cuando abras Claude Code en la carpeta donde hayas descomprimido el ZIP, **arrastra primero el `LEEME.md` y el `prompt.txt` a la ventana de Claude Code**, junto con tus CSV (los de ejemplo o los tuyos reales). Esto le da a la IA el contexto completo del caso antes de ejecutar: qué estás haciendo, qué datos manejas, qué entregable esperas y con qué estilo.

Si solo pegas el prompt sin el LEEME, Claude Code hará su trabajo igual, pero sin el matiz sectorial. Con los dos archivos de contexto cargados, el resultado sale directamente usable para una constructora PYME española.

Después, cambia las variables `[EMPRESA]`, `[MES AÑO]` y `[RUTA]` del prompt por los tuyos, pégalo y pulsa Enter.
