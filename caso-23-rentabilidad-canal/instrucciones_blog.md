# Cómo usar este pack en Claude Code

1. Copia los 4 archivos CSV a una carpeta de tu ordenador
2. Abre Claude Code en tu terminal
3. Arrastra el archivo `LEEME.md` y `prompt.txt` a la ventana de Claude Code junto con tus CSVs
4. Cambia las variables `[EMPRESA]`, `[MES AÑO]` y las rutas `TU_USUARIO` por las tuyas
5. Pulsa Enter y deja que trabaje

La IA necesita el LEEME.md para entender el contexto del análisis y el prompt.txt para ejecutar los 7 pasos del cálculo de rentabilidad real por canal.

Si quieres usar tus datos reales, el LEEME.md explica de dónde sacarlos en tu ERP (A3, Sage, Holded, SAP, Odoo).
