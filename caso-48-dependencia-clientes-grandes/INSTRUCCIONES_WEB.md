## Instrucciones para la web/blog

Dentro de este ZIP tienes tres cosas que necesita Claude Code para entenderte sin que tengas que explicarle nada:

1. **El archivo `LEEME.md`** → le da el contexto del problema y qué datos vas a usar.
2. **El archivo `prompt.txt`** → es la instrucción exacta que debe ejecutar.
3. **La carpeta `datos/`** → son los CSV con los que trabajará (sustitúyelos por los tuyos).

Cuando abras Claude Code en la terminal, **arrastra los tres a la ventana de chat** antes de pegar el prompt. Así la IA lee primero el contexto del problema, luego la instrucción, y por último los datos. Es la diferencia entre pedirle que trabaje a ciegas y pedirle que trabaje con la cabeza puesta.

Si solo pegas el prompt sin el LEEME, también funciona, pero el resultado será más genérico.
