## Cómo usar este pack (bloque para blog/web)

Descarga el ZIP y descomprímelo en tu ordenador. Dentro encontrarás tres archivos: `LEEME.md`, `prompt.txt` y `clientes.csv`.

Abre Claude Code en la carpeta del pack (`claude` en la terminal) y **arrastra los tres archivos** a la ventana de Claude Code antes de pegar el prompt. Es importante hacerlo así: el LEEME le da el contexto del caso, el CSV le da los datos y el prompt le da las instrucciones. Si le pegas solo el prompt sin los otros dos, Claude Code no sabe con qué está trabajando y el resultado pierde calidad.

Después pega el contenido de `prompt.txt`, ajusta las variables entre corchetes (`[EMPRESA]`, `[MES AÑO]`) con tus datos reales y pulsa Enter. En unos minutos tendrás las facturas HTML, la remesa SEPA en XML y los emails personalizados listos.
