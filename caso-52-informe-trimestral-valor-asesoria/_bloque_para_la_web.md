# Instrucciones para la web / blog

---

### Cómo usar este pack en Claude Code

1. **Descarga y descomprime** este ZIP en una carpeta de tu equipo (por ejemplo `C:\Informes_Clientes\Q1_2026\`).

2. **Abre Claude Code en esa carpeta**. Puedes hacerlo arrastrando la carpeta sobre el icono de Claude Code o abriendo tu terminal y ejecutando `cd` hasta llegar a ella.

3. **IMPORTANTE: arrastra a Claude Code tanto el `LEEME.md` como el `prompt.txt`** antes de ejecutar nada. Esto hace que la IA entienda primero el contexto completo (qué estamos haciendo, por qué y cómo se cruzan los datos) antes de ponerse a trabajar. Si solo pegas el prompt sin el LEEME, Claude Code hará su trabajo igual, pero perderá matices que marcan la diferencia en el resultado final.

4. **Sustituye los 3 CSVs** por los datos reales de tu cliente (manteniendo el mismo nombre de archivo y las mismas columnas).

5. **Pega el contenido de `prompt.txt`** en Claude Code y cambia las 3 variables:
   - `[EMPRESA]` → nombre del cliente
   - `[TRIMESTRE AÑO]` → ej. Q1 2026
   - `[RUTA]` → la ruta de tu carpeta

6. **Pulsa Enter** y espera. En 2-3 minutos tendrás el PDF listo para enviar al cliente.

> **Tip pro**: la primera vez te llevará 10 minutos entenderlo. A partir del segundo cliente, el proceso completo (desde que exportas los datos del ERP hasta que envías el PDF) se despacha en menos de 15 minutos.
