## Cómo usar este caso con Claude Code

1. **Descarga el ZIP** y descomprímelo en una carpeta de tu ordenador.

2. **Abre Claude Code** en tu terminal (`claude`).

3. **Arrastra los archivos al chat de Claude Code:**
   - Primero `LEEME.md` y `prompt.txt` → para que Claude entienda el contexto completo.
   - Después los dos CSV de ejemplo (`clientes_fiscal.csv` y `calendario_fiscal.csv`).

4. **Cambia las variables** del prompt:
   - `[EMPRESA]` → el nombre de tu asesoría
   - `[MES AÑO]` → el mes que quieres controlar
   - `@ruta/` → la carpeta donde tienes los archivos

5. **Pulsa Enter** y deja que Claude Code trabaje. En menos de 2 minutos tendrás un dashboard fiscal completo abierto en tu navegador.

💡 **Consejo:** Cuando lo pruebes con los datos de ejemplo y veas el resultado, sustituye los CSV por los datos reales de tu asesoría. El prompt funciona igual con 50 clientes que con 500.
