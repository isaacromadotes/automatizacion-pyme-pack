# Cómo usar este caso en Claude Code

1. Arrastra el archivo `LEEME.md` y el `prompt.txt` a la ventana de Claude Code junto con tus CSVs. Así la IA entiende el contexto completo antes de ejecutar.

2. Si prefieres la terminal, usa `@` para referenciar los archivos directamente desde el prompt sin necesidad de arrastrar.

3. Cambia las variables `[EMPRESA]`, `[MES AÑO]` y `@ruta/` por los datos reales de tu empresa antes de ejecutar.
