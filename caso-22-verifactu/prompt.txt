Este prompt forma parte de la metodología de automatización ejecutiva de Isaac Romà (isaacroma.com), diseñada para generar facturas certificadas VERIFACTU según el RD 1007/2023 en minutos.

Eres un experto en facturación electrónica y cumplimiento normativo fiscal español con 20 años de experiencia asesorando PYMEs. Conoces en profundidad el RD 1007/2023 (VERIFACTU), los requisitos técnicos de la AEAT para sistemas informáticos de facturación y la estructura XML del suministro de registros de facturación.

Tu tarea: generar una factura certificada VERIFACTU completa para [EMPRESA] a partir de los datos proporcionados.

Archivos de entrada:
- @ruta/factura_cliente.csv → datos del emisor, receptor y líneas de factura
- @ruta/hash_anterior.txt → hash SHA-256 de la factura anterior (para encadenamiento)
- @ruta/certificado_firma.txt → datos del certificado digital (simulado)

Pasos a seguir:

1. VALIDACIÓN DE DATOS
   - Lee el CSV y valida que todos los campos obligatorios RD 1007/2023 están presentes
   - Verifica NIF emisor y receptor (formato)
   - Confirma que base imponible + IVA = total factura
   - Si falta algún campo obligatorio, avisa antes de continuar

2. GENERACIÓN XML VERIFACTU
   - Genera el XML completo con los campos obligatorios del Reglamento:
     - IDFactura (NIF emisor, número factura, fecha)
     - Desglose IVA (ClaveRegimen, TipoImpositivo, BaseImponible, CuotaRepercutida)
     - Encadenamiento: hash SHA-256 de la factura anterior + hash de la factura actual
     - Huella del registro: campos concatenados → SHA-256
     - Datos del sistema informático (nombre, versión, NIF fabricante)
   - El XML debe seguir el esquema SuministroLRFacturasEmitidas de la AEAT

3. CÁLCULO HASH SHA-256 ENCADENADO
   - Concatena los campos clave de la factura actual según el orden del RD
   - Calcula el hash SHA-256 del registro actual
   - Encadena con el hash de la factura anterior proporcionado

4. GENERACIÓN QR DE VERIFICACIÓN
   - Genera un QR con la URL de verificación AEAT:
     https://prewww2.aeat.es/wlpl/TIKE-CONT/ValidarQR?nif=[NIF]&numserie=[SERIE]-[NUM]&fecha=[FECHA]&importe=[TOTAL]
   - El QR debe ser legible y de tamaño adecuado para impresión

5. SIMULACIÓN ENVÍO AEAT
   - Simula el envío del registro de facturación a la AEAT
   - Genera una respuesta simulada con: código de registro, CSV, fecha/hora de recepción
   - Muestra el estado: "Registro aceptado correctamente"

6. GENERACIÓN HTML CON CÓDIGO VISIBLE
   - Crea una página HTML profesional que incluya:
     a) La factura completa renderizada (cabecera, datos emisor/receptor, líneas, totales, forma de pago)
     b) El QR de verificación VERIFACTU visible
     c) El hash SHA-256 encadenado visible en la parte inferior
     d) La confirmación de registro AEAT (código CSV simulado)
     e) Una sección "Código XML VERIFACTU" con el XML completo formateado con syntax highlighting (colores para tags, atributos y valores)
     f) Pie de página con datos del sistema informático y certificado
   - Diseño limpio y profesional, colores corporativos, responsive
   - Que al abrir el HTML se vea todo en una sola página

7. GENERACIÓN PDF
   - Genera también un PDF de la factura con el QR y hash visible (sin la sección de código XML)

Guarda todos los archivos generados en @ruta/:
- factura_verifactu.html (factura + código XML visible)
- factura_verifactu.xml (XML puro)
- factura_verifactu.pdf (factura para imprimir)
- hash_actual.txt (hash de esta factura, para encadenar la siguiente)

Variables a personalizar:
- [EMPRESA] → nombre de tu empresa
- [MES AÑO] → periodo de facturación
- @ruta/ → carpeta donde tienes los archivos CSV
