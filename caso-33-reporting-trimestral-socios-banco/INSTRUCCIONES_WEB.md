### Cómo usar este pack

Dentro del ZIP encontrarás **5 archivos**: un `LEEME.md` con el caso completo, un `prompt.txt` con las instrucciones que ejecuta Claude Code, y 3 archivos CSV con datos ficticios de una constructora española.

**Paso crítico:** no te limites a copiar y pegar el `prompt.txt` en Claude Code. **Arrastra también el `LEEME.md` a la ventana de Claude Code junto con los CSV**, antes de ejecutar el prompt.

¿Por qué? Porque el `LEEME.md` le da a Claude Code el contexto completo del caso: qué problema se está resolviendo, qué significan los datos, qué formato espera el banco. Sin ese contexto, Claude Code generaría un informe genérico. Con él, genera uno diseñado específicamente para socios y bancos de constructoras españolas.

**Orden recomendado al abrir Claude Code:**
1. Arrastra el `LEEME.md`
2. Arrastra los 3 CSV
3. Arrastra el `prompt.txt`
4. Edita las variables `[EMPRESA]` y `[MES AÑO]` en el prompt
5. Pega el prompt completo y pulsa Enter

En 10–15 minutos tendrás tu informe HTML listo. Ábrelo en cualquier navegador, imprímelo o guárdalo como PDF (Ctrl+P → Guardar como PDF).

Si quieres conectarlo a los datos reales de tu empresa (A3, Sage, Holded, SAP, Odoo…), [agenda una reunión gratuita de 30 minutos aquí](https://calendly.com/asesor-online-ia/30min).
