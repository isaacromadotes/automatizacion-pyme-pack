## Cómo usar este pack

1. Descarga el ZIP y descomprímelo en tu ordenador (recomendado: `Downloads/Caso 21 Extras de obra/`).

2. Abre Claude Code en esa carpeta.

3. **Importante:** arrastra el `LEEME.md` y el `prompt.txt` dentro de la ventana de Claude Code junto con los tres CSVs. Esto hace que la IA lea todo el contexto — el problema, el flujo, los datos y las instrucciones — antes de ejecutar. Sin ese contexto la IA improvisa; con él, entrega exactamente lo que necesitas.

4. Cambia en el prompt las variables `[EMPRESA]`, `[MES AÑO]` y `@ruta/` por los tuyos.

5. Pulsa Enter y espera. Claude Code generará el sistema completo y arrancará un servidor local que verás en el navegador en un par de minutos.

6. Cuando tengas la web funcionando con los datos de ejemplo, sustituye los CSVs por tus datos reales (exportados de Presto, Arquímedes, Menfis, Sage o el ERP que uses) y vuelve a lanzar el prompt.
