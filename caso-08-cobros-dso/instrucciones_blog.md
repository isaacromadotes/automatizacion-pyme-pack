# Bloque para web/blog — Instrucciones de uso del pack

> **Cómo usar este pack con Claude Code**
>
> 1. Descarga y descomprime el ZIP en una carpeta de tu ordenador.
> 2. Abre Claude Code en tu terminal (`claude`).
> 3. Arrastra el archivo `LEEME.md` a la ventana de Claude Code para que entienda el contexto del caso.
> 4. Arrastra también el archivo `prompt.txt` — este es el prompt que ejecutará el análisis.
> 5. Si quieres probar con los datos de ejemplo, arrastra `facturas_emitidas.csv` y `maestro_clientes.csv`. Si prefieres usar tus datos reales, sustituye estos CSVs por los tuyos manteniendo las mismas columnas.
> 6. Antes de pulsar Enter, cambia las variables `[EMPRESA]`, `[MES AÑO]` y `@ruta/` por tus datos.
> 7. Pulsa Enter y deja que Claude Code trabaje. En unos minutos tendrás: dashboard web de cobros, emails de reclamación, Excel con antigüedad de deuda y PDF ejecutivo.
