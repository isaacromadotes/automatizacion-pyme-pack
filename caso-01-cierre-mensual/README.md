# Caso 01 · Cierre Mensual en 48h — De 10-15 días a 2 días con Claude Code

> Pack listo para implementar en PYMEs industriales españolas. Resultado: P&L mensual completo (ventas, márgenes, EBITDA, alertas) en 48 horas en lugar de 10-15 días.

## 🎯 Problema que resuelve

Tu cierre mensual tarda 10-15 días: recopilar datos del ERP, consolidar costes por centro, cruzar con ventas, calcular márgenes… todo manual. Mientras tanto, tu competencia ya cierra en 48h y toma decisiones con datos frescos. Este pack automatiza el P&L mensual completo con validación de descuadres, desglose por cliente, análisis por centro de coste y alertas automáticas de concentración y margen.

## 🚀 Cómo usarlo en 5 pasos

1. **Descarga** los archivos de esta carpeta.
2. **Abre** `prompt.txt` y cópialo.
3. **Pégalo** en Claude Code ([instalación aquí](https://docs.anthropic.com/en/docs/claude-code)).
4. **Cambia** `[EMPRESA]`, `[MES AÑO]` y `@ruta/` por tus datos reales.
5. **Pulsa Enter**: recibirás el P&L completo + alertas en formato web.

## 🔌 Cómo exportar los CSV desde tu ERP

| ERP | Balance | Costes producción | Ventas |
|---|---|---|---|
| **A3 / Wolters Kluwer** | Contabilidad → Sumas y Saldos → Exportar | Analítica → Centros coste | Facturación → Listado → Exportar |
| **Sage 50 / 200** | Informes → Balance → CSV | Analítica → Centros | Ventas → Facturas emitidas |
| **Holded** | Contabilidad → Balance → Exportar | Proyectos / Centros coste | Ventas → Facturas → Exportar |
| **SAP Business One** | Informes financieros → Sumas y Saldos | Contabilidad de costes | Ventas → Documentos → Exportar |
| **Odoo** | Contabilidad → Balance comprobación | Analítica → Posiciones | Facturación → Exportar |
| **Contasol / Contaplus** | Informes → Sumas y Saldos → CSV | Analítica → Centros | Facturación → Listado |

⚠️ **Diseñado para industria/fabricación** (centros tipo corte, soldadura, pintura, montaje). Para construcción, servicios o distribución hay que adaptar los centros.
