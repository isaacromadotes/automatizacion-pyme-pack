## Cómo usar este pack en 2 minutos

Dentro del ZIP encontrarás 4 archivos: `LEEME.md`, `prompt.txt`, `certificaciones.csv` y `promotores.csv`.

**Paso 1** → Descomprime el ZIP en una carpeta de tu equipo.
**Paso 2** → Abre Claude Code en esa carpeta (`claude` desde la terminal).
**Paso 3** → **Arrastra el `LEEME.md` y el `prompt.txt` a la ventana de Claude Code antes de pulsar Enter**. Esto es importante: así la IA entiende el contexto del caso, el sector y el objetivo del entregable antes de ejecutar.
**Paso 4** → Pega el contenido de `prompt.txt`, sustituye `[EMPRESA]` y `[MES AÑO]` por tus datos, y pulsa Enter.
**Paso 5** → En menos de 2 minutos tendrás el dashboard web abierto, el PDF ejecutivo y los emails de reclamación generados.

> 💡 Si quieres probarlo con tus propios datos reales, sustituye los dos CSV de ejemplo por los tuyos exportados del ERP (A3, Sage, Holded, SAP, Odoo…). Las columnas deben llamarse igual.
