### Descarga el pack completo del Caso 37

Dentro del ZIP encontrarás:

- **LEEME.md** — guía paso a paso de cómo usar el pack
- **prompt.txt** — el prompt listo para pegar en Claude Code
- **5 archivos CSV** con datos ficticios de una metalúrgica (escandallos, precios de compra, tiempos de producción, indirectos y precios de venta)

### Cómo usarlo en 60 segundos

1. Descomprime el ZIP en una carpeta de tu equipo
2. Abre Claude Code en tu terminal (`claude`)
3. **IMPORTANTE: arrastra el `LEEME.md` y el `prompt.txt` a la ventana de Claude Code junto con los CSVs**. Esto le da a la IA el contexto completo antes de ejecutar — sabrá qué estás resolviendo, con qué datos, y qué entregable esperas.
4. Edita el `prompt.txt` para poner el nombre de tu empresa y la ruta donde guardaste los archivos
5. Pega el prompt en Claude Code y pulsa Enter

En menos de 2 minutos tendrás:
- Una web interactiva con el coste real por referencia
- Un Excel con las fichas de coste y las alertas
- Un PDF ejecutivo con las referencias que vendes a pérdida
