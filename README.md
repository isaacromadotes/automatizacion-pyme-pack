Creado por **[Isaac Romà](https://isaacroma.com)** — economista, 20 años como CEO, CFO y COO en PYMEs industriales españolas de 1 a 50M€.

---

## ¿Qué es esto?

Una colección de **54 casos prácticos** de automatización empresarial resueltos con Claude Code. Cada caso incluye:

- **Prompt listo para usar** (`prompt.txt`) — pégalo en Claude Code y ejecuta
- **CSVs de ejemplo** con datos ficticios realistas (nombres, importes, fechas)
- **Guía paso a paso** (`LEEME.md`) con mapeo a ERPs reales: A3, Sage, Holded, SAP, Odoo, Contasol
- **Diseño visual** para los entregables (`diseno.txt`)

Resultado: dashboards HTML, Excels multipestaña, PDFs ejecutivos y secuencias automatizadas, en 5 minutos.

---

## Cómo usar un pack

1. Descarga la carpeta del caso que te interese
2. Abre Claude Code en esa carpeta
3. Arrastra el `LEEME.md` y el `prompt.txt` a la ventana de Claude Code
4. Añade tus propios CSVs (o usa los de ejemplo)
5. Pega el prompt y ejecuta

En el `LEEME.md` de cada caso tienes la ruta exacta de exportación para los ERPs más comunes en España.
