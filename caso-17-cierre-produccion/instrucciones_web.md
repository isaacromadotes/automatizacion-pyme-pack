# Instrucciones para el blog / web (bloque corto)

## Cómo usar este pack

1. Descarga el ZIP y descomprímelo en una carpeta de tu ordenador.
2. Abre Claude Code dentro de esa carpeta (`cd` + `claude`).
3. **Antes de pegar el prompt, arrastra a la ventana de Claude Code los dos archivos de contexto**: `LEEME.md` y `prompt.txt`. Esto le da a la IA el marco completo del caso (empresa ficticia, sector, objetivo del cálculo) antes de ejecutar nada.
4. Pega el contenido de `prompt.txt` en el chat, cambia `[EMPRESA]` y `[MES AÑO]` por los tuyos, y pulsa Enter.
5. Claude Code procesará los 4 CSVs y te abrirá la web con el resultado en 3-5 minutos.

**Consejo:** si vas a probarlo con datos reales de tu empresa, sustituye los CSVs por exports de tu ERP manteniendo la misma estructura. El LEEME.md incluye la equivalencia con SAP, Odoo, Sage, A3 y Holded.
