# Bloque para la web / blog

## Cómo usar este pack en Claude Code

Descarga y descomprime el ZIP. Verás 5 archivos: un LEEME.md, un prompt.txt y tres CSVs de ejemplo.

Para que Claude Code entienda el contexto completo antes de ejecutar, haz esto:

1. Abre la terminal y escribe `claude` para arrancar Claude Code
2. **Arrastra a la terminal el LEEME.md, el prompt.txt y los 3 CSVs juntos** — así la IA lee primero las instrucciones y el sector, y solo después ejecuta el prompt sobre los datos
3. Pega el contenido de prompt.txt, sustituye las variables entre corchetes ([EMPRESA], [MES AÑO], [RUTA]) por tus datos reales
4. Pulsa Enter

En menos de 3 minutos tendrás el cuadro de mando funcionando en tu navegador y el PDF con el flujo de aprobación en la misma carpeta.

**Importante**: los CSVs de ejemplo son ficticios pero realistas. Cuando quieras usarlo con tu empresa, sustituye cada CSV por la exportación equivalente de tu ERP manteniendo la misma estructura de columnas.
