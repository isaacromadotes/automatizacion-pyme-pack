## Bloque para la web/blog — instrucciones al descargar

**IMPORTANTE — Cómo usar este pack en Claude Code**

Cuando abras Claude Code en tu terminal, **arrastra a la ventana estos dos archivos ANTES de pegar el prompt**:

1. `LEEME.md` — para que Claude entienda el contexto del problema
2. `prompt.txt` — para que ejecute la metodología

Después, arrastra también los tres CSV (partes_semana.csv, presupuesto_mod.csv, obras_activas.csv).

Con los cinco archivos cargados, Claude tiene el contexto completo: sabe qué problema resuelve, qué metodología aplicar y con qué datos trabajar. Solo entonces pulsa Enter.

Si pegas el prompt directamente sin arrastrar el LEEME, la IA funciona igual pero pierde el contexto de por qué está haciendo esto, y el resultado puede ser menos ajustado a lo que necesitas.
