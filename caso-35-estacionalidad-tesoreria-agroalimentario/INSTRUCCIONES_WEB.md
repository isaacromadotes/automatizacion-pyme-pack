# Instrucciones para la web / blog

Copia este bloque en la ficha del caso en isaacroma.com:

---

**Cómo usar este pack**

1. Descarga el ZIP y descomprímelo en una carpeta de tu equipo.
2. Instala [Claude Code](https://docs.claude.com/en/docs/claude-code/overview) si todavía no lo tienes.
3. Abre la terminal **dentro de la carpeta descomprimida** y ejecuta `claude`.
4. **Arrastra `LEEME.md` y `prompt.txt` a la ventana de Claude Code** — así la IA entiende el contexto completo del caso antes de ejecutar.
5. Si vas a usar los CSVs de ejemplo, arrástralos también. Si vas a usar tus datos reales, sustitúyelos manteniendo el mismo nombre de archivo y estructura de columnas.
6. Pega el contenido de `prompt.txt` en Claude Code, sustituye las variables entre corchetes (`[EMPRESA]`, `[MES AÑO]`) y pulsa Enter.

En unos minutos tendrás una web local con el forecast, un Excel navegable y un dashboard HTML listo para presentar al banco.
