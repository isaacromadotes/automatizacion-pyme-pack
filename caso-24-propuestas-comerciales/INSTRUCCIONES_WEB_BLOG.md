### Cómo usar este pack (3 minutos de setup)

1. **Descarga el ZIP** y descomprímelo en una carpeta de tu ordenador.
2. **Abre Claude Code** en esa carpeta (si no lo tienes instalado: `npm install -g @anthropic-ai/claude-code`).
3. **Arrastra a la ventana de Claude Code** los siguientes 3 archivos del pack antes de ejecutar nada:
   - `LEEME.md` → para que la IA entienda el contexto completo del caso
   - `prompt.txt` → el prompt que va a ejecutar
   - Los 4 CSVs (`prospecto.csv`, `plantilla_propuesta.md`, `casos_exito.csv`, `servicios_pricing.csv`)

   > Este paso es clave. Si solo pegas el prompt sin dar los archivos de contexto,
   > la IA no sabe de qué cliente hablas ni qué casos de éxito tienes disponibles.

4. **Abre `prompt.txt`** y sustituye las variables entre corchetes `[EMPRESA]`, `[MES AÑO]`
   y `[RUTA_SALIDA]` por tus datos. Si solo quieres probar con el ejemplo, déjalas como están.
5. **Pega el prompt entero** en Claude Code y pulsa Enter.
6. En 2-3 minutos tendrás en la carpeta `output/`:
   - Una propuesta web espectacular en HTML (ábrela en Chrome)
   - La misma propuesta exportada a PDF para enviar
   - Un email de presentación listo para pegar en Outlook/Gmail
