## Cómo usar este caso con Claude Code

1. **Descarga el ZIP** y descomprímelo en una carpeta de tu ordenador
2. **Sustituye los CSVs de ejemplo** por tus datos reales (respetando las mismas columnas)
3. **Abre Claude Code** en tu terminal (`claude`)
4. **Arrastra el archivo `LEEME.md`** a la ventana de Claude Code para que entienda el contexto del caso
5. **Arrastra el archivo `prompt.txt`** junto con tus tres CSVs
6. **Cambia las variables** entre corchetes: `[EMPRESA]`, `[MES AÑO]` y las rutas `@ruta/`
7. **Pulsa Enter** y espera a que Claude Code genere el dashboard

El resultado es un archivo HTML interactivo con el ranking de rentabilidad de todos tus clientes, semáforo visual y recomendaciones accionables para tu próxima reunión de dirección.
